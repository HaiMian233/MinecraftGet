# PCL 下载页限制解除脚本（个人研究用途）

一个单文件 Windows 批处理脚本，用于在**本地**修改 Plain Craft Launcher 2 可执行文件中被编译期移除的「下载 Minecraft 本体」入口，使其恢复可用。

## 工作原理

PCL 通过编译期常量关闭了下载页的版本列表功能，编译后 `PageDownloadInstall.LoaderInit` 中只剩下一个「关闭下载」的必然中断任务，真正的 `DlClientListLoader` 加载逻辑已从 IL 中消失。

脚本做的是：

1. 读取 exe 字节流；
2. 在固定偏移处比对一段**特征字节**（非法转移指令 + 字符串常量），确认确实是目标版本的方法体；
3. 校验通过后，用 `ldsfld PCL.ModDownload.DlClientListLoader` 指令替换该任务构造序列，并把剩余填充区清零；
4. 首次修改前生成 `Plain Craft Launcher 2.exe.bak` 备份；
5. 写入后重新读取文件进行校验。

若特征字节不匹配（版本不符）或已是修改后状态，脚本会直接退出，不会改动文件。

## 使用方法

1. 从官方渠道获取并解压 PCL；
2. 将 `一键解除PCL下载限制.bat` 放到与 `Plain Craft Launcher 2.exe` **同级**的目录；
3. 完全退出 PCL（脚本会检测残留进程）；
4. 双击运行脚本，按提示操作；
5. 打开 PCL → 下载 → 原版游戏，即可看到版本列表。

## 还原

删除当前 `Plain Craft Launcher 2.exe`，然后把 `Plain Craft Launcher 2.exe.bak` 改名回 `Plain Craft Launcher 2.exe`。

## 已知限制

- 偏移与特征字节均针对 2.99.0.0 (413) 硬编码，**换版本必然失效**（会安全退出，不会损坏文件）；
- PCL 若自动更新，限制会重新出现，需重新运行脚本；
- 整合包安装等其他限制属于另一段同样被编译期删除的代码，本脚本无法恢复。
